# Bellui X — editor

Embeddable code-editor widgets for Bellui (Bellui Editor).

This module is part of the **Bellui X** umbrella: each `x/*` directory is its
own Go module so the core `github.com/belluikit/bellui` dependency graph stays
lean and consumers only pull in what they use.

```
go get github.com/belluikit/bellui/x/editor
```

## Status

**Scaffold only.** The implementation is migrated from `trendvidia/fycoder` as part of
the ecosystem rebrand — tracked by trendvidia/fycoder#170. Until that lands this module
intentionally contains no packages.
