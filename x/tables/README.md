# Bellui X — tables

Advanced table widgets for Bellui.

This module is part of the **Bellui X** umbrella: each `x/*` directory is its
own Go module so the core `github.com/belluikit/bellui` dependency graph stays
lean and consumers only pull in what they use.

```
go get github.com/belluikit/bellui/x/tables
```

## Status

**Scaffold only.** The implementation is migrated from `trendvidia/fytables` as part of
the ecosystem rebrand — tracked by trendvidia/fytables#75. Until that lands this module
intentionally contains no packages.
