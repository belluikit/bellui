* **x/mmedia: a dropped network stream is reported as an error, not as the end of the track**
  ([#839](https://github.com/belluikit/bellui/issues/839)). When the
  connection dropped partway through a file or stream, the player called
  `OnEnd` and jumped the position to the full duration, so an app could not
  tell a finished track from a lost one. It now calls `OnError` with FFmpeg's
  error (`input/output error` for a dropped HTTP connection), leaves the
  position where playback stopped, and the play button returns to "play". A
  clean end is still `OnEnd`. Retrying in place is limited: the same player
  keeps FFmpeg's failed connection, so playing it again replays from the
  start but may end on the error again; opening the URL again is the
  reliable retry.
