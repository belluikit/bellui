* **A two-finger trackpad swipe opens a DataGrid row's actions on macOS and
  Wayland** ([#1483](https://github.com/belluikit/bellui/issues/1483)). It
  follows the same rules as a touch swipe. The gesture scrolls the grid while
  the grid can still move that way, and swipes the row only when it starts
  with the grid already at that edge. Lifting the fingers opens the row, closes
  it, or runs a full-swipe action. The coast after the fingers lift never
  swipes and doesn't scroll the grid on. Windows, X11 and browsers don't report
  when a trackpad gesture begins and ends, so there a trackpad only scrolls
  the grid (#1514). Their users reach the same actions from the context menu.
