* **x/tables: a column can have an empty header**
  ([#918](https://github.com/belluikit/bellui/issues/918)). A column of icons
  usually needs no header text, but an empty `HeaderName` falls back to
  `Field`, so there was no way to leave the header blank. Set the new
  `ColumnDef.HideHeaderText` and the header cell shows no text. The column is
  still named everywhere else: screen readers read `HeaderName` (else
  `Field`), and exports and the filter popup use it as the column's title.
  An unset `HeaderName` still falls back to `Field`.
