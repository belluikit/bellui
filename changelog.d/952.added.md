* **`widget.Icon` has a `Color` field**
  ([#952](https://github.com/belluikit/bellui/issues/952)). Tinting an icon
  meant wrapping its resource with `theme.NewColorizedResource`, so changing
  the icon or the colour needed the current value of the other. `Color`
  tints the icon with a fixed colour and keeps the tint when the resource
  changes. nil, the default, draws the resource as given, following the
  theme. A resource that is not an SVG is drawn unchanged.
