* **x/tables: DataGrid rows can be moved by touch**
  ([#1512](https://github.com/belluikit/bellui/issues/1512)). A column with
  `ColumnDef.RowDragHandle` draws a grip on each row: dragging a grip moves
  its row at once, by finger or mouse, and with a grip column the mouse moves
  rows only from it. Holding a row still and then dragging moves it from
  anywhere; holding and lifting still opens the context menu. The grips are
  drawn disabled while a sort, grouping, pivot or tree data orders the rows.
  A plain swipe still scrolls.
