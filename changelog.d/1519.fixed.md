* **A notification sent while the permission prompt is up is no longer lost
  on iOS or macOS** ([#1519](https://github.com/belluikit/bellui/issues/1519)).
  Each send asked for permission itself, and the answer a request gets is not
  always the user's. On iOS, two pending requests and a tap on Allow lost one
  notification entirely. On macOS, the second request was refused at once and
  that notification was shown through AppleScript instead, under another
  app's name and with no click callback or actions. The same happened when
  the user answered from System Settings. Now one request is made at a time,
  sends made meanwhile wait for its answer, and the permission the system
  stored decides, including one turned on in System Settings within a minute.
  Both plain and rich notifications now ask for alerts and sounds.
