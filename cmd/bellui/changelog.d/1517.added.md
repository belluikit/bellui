* **`aps-environment` follows the build kind**
  ([#1517](https://github.com/belluikit/bellui/issues/1517)). Write
  `$(APS_ENVIRONMENT)` in `ios/Entitlements.plist` and `bellui package`
  signs in `development`, `bellui release` `production`. `bellui release`
  refuses any other literal value, since a store build with development push
  gets sandbox tokens that production pushes never reach.
