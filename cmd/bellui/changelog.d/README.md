# cmd/bellui/changelog.d: one file per change to the bellui command

Changes to the `bellui` command add one file here instead of editing
`cmd/bellui/CHANGELOG.md`. Naming, contents and commands are as in the
toolkit's [`changelog.d/README.md`](../../../changelog.d/README.md); pass
`-C cmd/bellui` to `preview` and `release`.
