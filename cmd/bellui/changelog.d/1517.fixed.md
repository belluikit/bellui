* **iOS simulator builds keep their entitlements**
  ([#1517](https://github.com/belluikit/bellui/issues/1517)). A
  `-os iossimulator` package was re-signed ad hoc, which dropped every
  entitlement, so registering for push failed with "no valid
  aps-environment entitlement string". The entitlements are now linked into
  the binary's `__TEXT,__entitlements` section, where the simulator reads
  them, as Xcode does.
