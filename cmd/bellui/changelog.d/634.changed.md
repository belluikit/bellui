* **The default icon is the Bellui logo, and the web splash screen has a new
  gopher and readable text**
  ([#634](https://github.com/belluikit/bellui/pull/634)). An app packaged
  without an `Icon.png` now gets the logo bellui.com shows. The web splash
  spinner is a 3D gopher skipping rope, and the splash text uses Roboto, the
  app's own font, where the device has it and the system's UI font elsewhere,
  instead of the browser's default serif. No font file is added to the page.
