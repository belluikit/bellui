* **macOS and iOS apps are about 3 MB smaller**
  ([#521](https://github.com/belluikit/bellui/issues/521)). `bellui build`
  and `bellui package` now pass `-dead_strip` to Apple's linker, which Go's
  link leaves out, so native code nothing calls is no longer linked in. A
  stripped macOS arm64 build of the frame benchmark goes from 35.80 MB to
  32.66 MB; nearly all of the saving is in wgpu-native.
