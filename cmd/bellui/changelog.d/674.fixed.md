* **`bellui package -os android` and `bellui release -os android` find the
  Android build tools on Windows**
  ([#674](https://github.com/belluikit/bellui/issues/674)). The build-tools
  programs were looked up by their Unix names, but Windows ships `d8.bat`,
  `apksigner.bat` and `zipalign.exe`. Apps with `android/*.java` or
  `android/libs` could not be dexed, and debug APKs were not re-signed with
  the v2 scheme Android 11 and later require. The `.bat` tools now run through
  `cmd.exe` with every argument quoted; an argument it would alter (one
  holding `%`, `!`, `^`, `"` or a line break) is refused with an error rather
  than passed on changed. d8 reads its arguments from a file, so many class
  files no longer approach `cmd.exe`'s command-line limit. `bellui release`
  hands apksigner the keystore and key passwords through the environment
  instead of the command line, so a password may hold any character.
